# Weather AI Agent

A conversational AI agent that leverages OpenAI's function-calling capability to fetch and deliver real-time weather information in natural language.

## Key Features
- Implemented an architecture that allows the agent to decide independently when and how to query external data sources based on user intent.
- Integrates seamlessly with live Weather API data to provide accurate updates.
- Streamlines user interaction by removing manual query-handling logic entirely.

## Tech Stack
- Language: Python
- Frameworks: FastAPI
- LLM & APIs: OpenAI API, Weather API
